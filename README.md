# pairwise-vehicle-suspension

越野车连续过搓板路时轮子陷地、悬挂爆炸、车身抖：轮子射线只打静态地形；弹簧阻尼按渲染帧积分；防倾杆左右轮相位错；轮胎摩擦圆用线性近似；差速器锁止条件只看转速差；高速时射线穿透薄板；坡度上重力分量没投影到悬挂轴；载荷转移只算重心不考虑悬挂行程；固定步长和物理材质更新不同步；回放时输入采样率不一致。physics/vehicle_suspension.py 是核心，tests/test_vehicle_suspension.py 15个红。要修的是：动态与静态碰撞分层；固定步长积分；防倾杆同步；摩擦圆耦合；差速器锁止阈值；连续射线；坡度投影；载荷转移含行程；材质同步；输入重采样。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
